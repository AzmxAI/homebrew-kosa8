# homebrew-kosa8

Homebrew tap for [kosa8](https://kosa8.com) — run AI coding assistants in
sealed machines you can save and copy.

```sh
brew tap AzmxAI/kosa8
brew install kosa8
```

Upgrade later with `brew upgrade kosa8`.

The formula is regenerated by CI on every release, so new versions appear
without a manual edit.

**Apple Silicon Macs** get the full runtime (`kosa8` and `kosa8d`).
**Intel Macs** get the command-line tool only — the part that runs containers
needs Apple's Virtualization framework, which is Apple Silicon only. On Intel,
point `kosa8` at an Apple Silicon Mac with `KOSA8_HOST` and `KOSA8_TOKEN`.
